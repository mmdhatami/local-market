# بازار

بازار هوشمند محلی برای خرید، فروش، خدمات، کسب‌وکارها و فرصت‌های محلی.

## معماری

این پروژه به صورت Monorepo طراحی شده است.

### Web

مسیر:

`apps/web`

تکنولوژی:

- React
- TypeScript
- Vite

### Android

مسیر:

`apps/mobile`

تکنولوژی:

- React Native
- Expo

### Backend

مسیر:

`services/api`

تکنولوژی:

- Cloudflare Workers
- Hono

### Database

مسیر:

`database`

دیتابیس اصلی:

- Cloudflare D1

### Shared

مسیر:

`packages/shared`

مدل‌ها و Typeهای مشترک بین Web، Android و API.

## هدف معماری

Web و Android از یک Backend و یک Data Model مشترک استفاده می‌کنند.

دامنه و زیرساخت قابل تغییر هستند و نباید URL موقت Cloudflare در بخش‌های اصلی برنامه Hardcode شود.
